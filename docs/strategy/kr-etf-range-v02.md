# kr-etf-range v0.2 — 구현 기준 사양

작성일 2026-09-11. 사용자 합의: 모의 전용, 2주 판단, KODEX 코스닥150(229200), 30분 상태 판단 + 5분 구간, 단일 매수 A와 3단 균등 매수 B 비교. 이 문서가 v0.1의 시간·윈도 설정을 대체한다. 수익성은 미검증이다.

## 일정과 활성화

- 실행기는 EC2 부팅 시 시작한다. 09:00부터 당일 호가·체결 수집, 최소 30분 연속 관찰 후 09:30~15:15 신규 진입. 서버를 늦게 켜면 30분 준비부터 다시 시작한다.
- 15:15부터 신규 매수 금지, 모든 미체결 취소·보유 청산. 15:20 이전 완료 목표이며 미청산은 성공 처리하지 않는다. 장 마감 후에도 미확인 상태를 표시한다.
- 실험 시작일·종료일을 명시해 최대 14일 달력 구간에서 수집한다. 휴장일은 자동 매매일로 계산하지 않는다. 최대 10개의 실제 시세 관찰일을 기록한다. 자동 기간 연장 없음.
- 1일차는 관찰, 2일차는 취소·체결 사전 검증 단계, 3~10일차 A/B 교대. 날짜만 지났다고 검증을 통과시키지 않는다.
- 자동 취소 검증 옵션: 2일차 이후 09:30~15:00, 30분 시세 준비와 계좌 대조 후 현재 매수호가보다 2% 낮은 지정가로 1주만 주문하고 취소한다. 취소 접수 응답만으로 통과하지 않는다. 증권사 조회에서 취소 완료·체결 0·계좌 잔고 0을 확인해야 통과한다. 예상 밖 체결은 미체결 정리 후 시장가 청산하고 검증 실패로 중단한다. 실패한 시험은 자동 반복하지 않는다. 이 시험은 취소 경로 검증이며 전략의 수익성이나 모든 체결 경로의 검증을 의미하지 않는다.
- 주문 활성화에는 모의 전용 설정, 명시된 실험 날짜, 취소 검증 완료, 출처가 기록된 실험 수수료가 모두 필요하다. 부족하면 시세와 판단만 저장하며 이유를 화면에 표시한다.

## 데이터와 시장 상태

- KRX WebSocket 최우선 호가·잔량 및 체결 수신. 수신 시각과 제공 시각을 함께 저장한다. 주문은 KIS 모의 REST만 사용한다.
- 중간가격을 초당 최대 1개 표본으로 만들어 최근 30분 보관한다. 30분 구간 90% 이상 표본, 관찰 간격 최대 10초, 최초~최종 29분 50초 이상을 요구한다. 연결 중단이면 윈도 초기화.
- 최근 30분 ER = 시작~끝 절대변화 / 인접 변화 절댓값 합 ≤0.25. 최근 5분 ER도 ≤0.25. 분모 0은 진입 금지.
- 급변 감시: 최근 60초 가격 폭이 앞선 4분 폭의 2배 초과이면서 4틱 초과면 진입 중단, 보유 중이면 취소·청산. 이 수치는 최적값이 아닌 고정 초기 가설.
- 최근 5분 완료 표본의 최소 L·최대 U, W=U−L. 현재 표본은 경계 산출에서 제외한다. 미보유 시 분당 1회 평가, 구간 유효 60초. 주문·보유 중 경계와 손절선 이동 금지.
- 스프레드 ≤10원, 호가·체결 시각 최신성, 실제 당일 연속매매 시세를 요구한다. 시간만으로 휴장일 개장 처리하지 않는다. 이상·단절 시 신규 진입 금지.

## 가격·수량

- ETF 5원 틱. 매수 가격 내림, 매도 가격 올림. 겹치는 3단 매수·부족한 폭은 제외.
- A: L+0.2W 매수, L+0.6W 매도. B: L+0.3W/0.2W/0.1W 매수, 각 실제 체결 평균가+0.3W 매도.
- 최초 B는 단계당 1주, A는 총 3주 이내. 연결 시험은 별도 1주이며 전략 성과에서 제외. 자동 수량 확대 없음.
- 최대 전체 매입 노출 30만 원, 가상 자본 100만 원, 박스 손절 예산 2천 원. 미체결 매수 전량까지 포함. 손절 가격 L−0.1W에 불리한 체결 2틱과 수수료를 반영해 초과 시 진입하지 않는다.
- 목표폭 ≥실제 설정 수수료·적용세금 + 불리한 체결 2틱 + 여유 1틱. 비용을 중복 차감하지 않는다.

## 주문 생명주기와 청산

- 매수는 10초 유효, 최초 체결부터 최대 120초 보유. 추가 체결로 보유시간 연장 금지.
- 부분 체결은 누적 체결수량과 누적 금액의 차분으로 원장에 반영. 매수 잔량이 끝난 후 확인된 수량만 목표 매도한다.
- 손절, 급변, 시세 단절, 일일 손실 한도, 최대 보유, 15:15, 종료 요청 시 청산 모드. 먼저 모든 기존 미체결 주문 취소·결과 대조 후 실제 보유량 시장가 청산. 시장가도 미체결·거절 가능하므로 확인 완료 전 종료 완료 표시 금지.
- 주문 전 의도를 SQLite에 동기 저장. 응답 유실은 UNKNOWN으로 영속화하고 자동 재주문 금지. 불명확한 취소도 재전송하지 않고 상태 조회로 해결하거나 수동 확인.
- 예상하지 못한 주문·수량 불일치는 중단·노출 표시. 사용자 수동 주문이나 다른 봇과 같은 모의계좌 공유 금지.
- 재진입 60초 대기, 같은 가격 구간 최대 2회, 일일 최대 30박스, 3연속 손실 또는 일일 실현+평가 순손익 -1만원이면 신규 중단. 손절 금액은 보장된 손실 상한이 아니다.

## 원장·분석·복구

- SQLite: 전략 버전·설정 해시, 주문 의도/응답/체결/취소, 구간·거절 이유, 시세, 잔고 대조, 실현·평가손익. 실전 키는 저장하지 않는다.
- 컨테이너 외부 볼륨 영속화. 상태 단독 작성자 lease, 종료 완료 시 일별 DB 백업. 서버 디스크 소실에 대비한 외부 백업은 별도 운영 항목.
- 로컬 HTTP 조회 화면·JSON·CSV 보고서 제공. 공개 포트 대신 SSH 터널로 접근. Vercel 연동은 공개 인증 설계가 필요해 이 배포에 포함하지 않는다.
- 가상 A/B 평가와 실제 KIS 모의 결과를 명확히 구분. 가상 지정가 체결은 큐를 재현하지 못하므로 수익 증거로 사용하지 않는다.
- 5일차·종료일 보고: 순손익, 비용, 낙폭, 거래·미체결, 재고, 취소 지연, 진입 제외 이유. 2주 후 유지·수정·보류. 표본 부족은 그대로 보고.

## 배포 전 필수 검증

가격 격자·윈도 준비·추세/급변 필터·종료 시간·기간 만료·비용·부분체결·취소 경합·중복 방지·응답 유실·재시작·lease·일일 손실 한도 테스트. KIS 연결이 되더라도 취소 검증/수수료가 미확정이면 관찰 모드로 배포하고 상태를 명시한다. 과거 연결 테스트 타이머는 새 실행기 활성화 전에 중지한다.
