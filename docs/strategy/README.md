# 전략 문서

이 폴더는 이 저장소에서 운용을 검토하는 매매 전략의 **사양서**를 둔다. 전략을 고른 배경과 근거는 [`docs/trading-strategy-research.md`](../trading-strategy-research.md)에, 계좌·주문·백테스트 기반 작업 순서는 [`docs/research-and-revision-plan.md`](../research-and-revision-plan.md)에 있다.

여기 있는 문서는 사양이지 수익 보장이 아니다. 모든 전략은 아래 상태 중 하나를 가지며, `검증됨` 이전 단계의 전략을 실전에 올리지 않는다.

| 상태 | 의미 |
| --- | --- |
| `초안` | 규칙만 정의됨. 코드·데이터·백테스트 없음 |
| `구현됨` | 코드로 존재하고 단위 테스트 통과. 성과는 미검증 |
| `백테스트됨` | 실제 이력 데이터로 비용 차감 후 결과 확보. 채택 여부는 미정 |
| `모의검증중` | paper 모드 관찰 기간 진행 중. 기간·판정 기준은 해당 실험 계획을 따름 |
| `검증됨` | 채택 조건 충족. 소액 실전 전환 판단 가능 |
| `보류` | 검증에서 탈락. 기록 보존용 |

## 전략 목록

최신 구현 기준: [kr-etf-range v0.2](./kr-etf-range-v02.md). 30분/5분 윈도와 09:30~15:15 진입 규칙을 반영한다.

현재 합의된 실험은 [ETF 구간 스캘핑 2주 계획](./kr-etf-range-paper-v01.md)이다. 10거래일 기준으로 유지·수정·보류를 판단하며 아직 실행을 시작하지 않았다.

현재 사용자가 원하는 방향은 **스캘핑**이다. 아래 저빈도 ETF 전략은 기존 비교 자료이며, 현재 주력으로 채택된 전략이 아니다.

| 전략 | 파일 | 버전 | 상태 |
| --- | --- | --- | --- |
| ETF 구간·유한 그리드 스캘핑 | [2주 모의 계획](./kr-etf-range-paper-v01.md) | v0.1 | `초안` |
| 국내 ETF 저빈도 추세추종 | [`kr-etf-trend-120.md`](./kr-etf-trend-120.md) | v0.1 | `초안` |

## 명명 규칙

- 파일명과 전략 ID는 같은 kebab-case를 쓴다: `kr-etf-trend-120`.
- 전략 ID에는 시장(`kr`), 상품군(`etf`), 계열(`trend`), 핵심 파라미터(`120`)를 넣는다.
- 규칙이 바뀌면 버전을 올린다. 파라미터 값만 바뀌어도 `v0.1 → v0.2`로 올리고 변경 이력에 남긴다. 백테스트·모의·실전 기록은 항상 전략 버전과 함께 저장한다.
- 탈락한 전략과 불리한 검증 결과는 지우지 않고 상태를 `보류`로 바꿔 보존한다. 좋은 결과만 남기면 그 뒤의 모든 검증이 무의미해진다.
