# 국내 ETF 추세추종 — 진입 후 보유 전략

작성일: 2026-09-10 | 제안: Codex | 버전: v0.1 | 상태: 초안·수익성 미검증

## 목적

100만 원 규모에서 거래 횟수와 비용을 줄이며 검증할 첫 전략 후보다. 월 10만 원 수익을 보장하거나 예상하지 않는다. 기대 수익률은 백테스트 전까지 미정이다.

## 핵심 규칙

| 항목 | 규칙 |
| --- | --- |
| 대상 | 국내 주가지수 ETF 1개. 레버리지·인버스·테마 상품 제외. 종목은 검증 전에 선정·고정 |
| 신호 | 전 거래일 수정 종가와 해당 날짜를 포함한 최근 120거래일 수정 종가의 단순평균 비교 |
| 판단 시각 | 매주 첫 개장일 오전 10시 30분, 한국 시간 |
| 매수 | 종가가 이동평균보다 높고 보유·미체결·미확인 주문이 없을 때 진입 |
| 보유 | 매수 후에는 비중 복원을 위한 추가 매수나 정기 부분 매도를 하지 않음 |
| 매도 | 종가가 이동평균보다 낮으면 보유 수량 전부 매도 |
| 같은 가격 | 기존 상태 유지. 미보유라면 현금 대기 |
| 보유 기간 | 매도 신호가 발생할 때까지. 당일 청산 의무 없음 |

120일은 최적값이 아니라 연구 시작값이다. 첫 버전에는 완충 구간이나 별도 가격 손절선을 추가하지 않는다.

## 자금과 수량

- 전략에 배정한 가상 원금은 100만 원이다. 모의계좌의 큰 잔고나 다른 보유 자산을 자동으로 편입하지 않는다.
- 신규 진입 금액은 전략 순자산의 60% 이내로 제한한다. 지정가와 예상 매수 비용, 실제 매수가능액을 반영해 정수 수량을 계산한다.
- 60%는 **진입 시 한도**다. 이후 가격 변동으로 비중이 바뀌어도 60%로 되돌리지 않는다.
- 실제 모의 주문의 초기 실행 검증은 1주로 한다. 1주 실행 결과와 60% 투자 백테스트 성과는 구분한다.
- 매도 신호가 나오면 소액 잔여분도 청산한다. 최소 비중 차이 때문에 매도를 생략하지 않는다.
- 신용·미수·레버리지는 사용하지 않는다.

## 실행과 장애 처리

- 정규장·최신 시세·120거래일 데이터 무결성을 확인한 뒤 지정가로 주문한다. 정확한 가격 허용폭은 실행 설정으로 고정하고 기록한다.
- 동시 실행 잠금과 주문 전 영속 기록을 사용한다. 미체결·미확인 주문이 있으면 새 주문보다 조회·대조를 먼저 수행한다.
- 10분간 미체결이면 취소 요청 후 취소·체결 상태를 확인한다. 첫 버전은 당일 자동 재주문을 하지 않는다.
- 매수 부분 체결 후 취소가 확인되면 체결된 수량만 보유하고 추가 매수하지 않는다. 매도 잔량은 청산 대기 상태로 보존하고 다음 거래일 실행 시간에 재확인해 처리한다.
- 재시작 시 청산 대기 주문은 새 신호보다 먼저 처리한다. 상태가 불명확하면 자동 재전송하지 않는다.
- 해당 주의 첫 실행을 놓쳤다면 다음 개장일 10시 30분에 한 번 실행한다. 그 실행일 직전 종가로 판단하고 처리한 주를 기록한다. 지난 여러 주의 주문을 몰아서 실행하지 않는다.
- 중지 상태는 EC2 영속 파일로 관리할 수 있다. 신규 매수 중지와 전체 프로세스 중지를 구분하며, 신규 매수 중지 중에도 기존 보유분의 매도 판단·취소·조회는 계속한다.

서버가 꺼져 있으면 주문과 위험 대응도 실행되지 않는다. 이 전략은 밤사이 가격 급락과 주간 판단 사이의 하락을 감수한다. 이동평균 매도 규칙은 최대 손실을 보장하지 않는다. 별도 계좌 손실 중지선을 도입하면 그 동작과 재개 조건도 백테스트에 포함한다.

## 검증 방법

1. 같은 ETF·기간·원금으로 이 전략, 클로드의 60% 비중 조정 전략, 단순 보유를 비교한다. 투자 규모를 맞춘 단순 보유도 포함한다.
2. 전일 확정 데이터로 신호를 만들고 다음 거래일에 체결한다. 일봉만 있다면 다음 날 시가를 대체 가정으로 명시한다. 10시 30분 실행 성과를 주장하려면 해당 시간 데이터를 확보한다.
3. 수수료·상품별 세금·슬리피지·분배금을 일관되게 반영하고, 분배금을 수정 가격과 현금 수익에 이중 계산하지 않는다. 서버비 포함 결과도 별도로 보고한다.
4. 시간순으로 개발·선택·최종 평가 구간을 분리한다. 최종 평가 결과를 보고 규칙을 수정하면 새로운 미사용 구간이 필요하다.
5. 순수익, 최대 낙폭, 회복 기간, 거래 횟수, 평균 투자 비중을 비교하고 비용을 높인 경우도 확인한다.
6. 모의투자에서는 주문·체결·잔고 일치를 검증한다. 짧은 기간의 모의 수익이나 모의 체결 비용을 실전 성과로 간주하지 않는다.

채택 여부는 비용 후 성과와 단순 보유 대비 이점, 감당 가능한 낙폭을 확인한 후 결정한다. 현재는 어느 전략의 수익성이 더 높은지 확인되지 않았다.
