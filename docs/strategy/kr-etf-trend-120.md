## 1. 설계 원칙

이 전략은 수익률을 최대화하려고 만든 것이 아니라 **100만 원 계좌에서 검증이 성립하도록** 만든 것이다. 네 가지 제약이 모든 설계 결정을 지배한다.

1. **비용이 성과를 지배한다.** 100만 원 규모에서 왕복 비용은 개별주 약 0.33%, ETF 약 0.13%다. 회전율이 전략의 우열보다 크게 작용하므로 거래 빈도를 최소화한다.
2. **파라미터가 적을수록 검증이 유효하다.** 자유도가 커질수록 과거 데이터에 우연히 맞춘 결과를 고르기 쉽다. v0.1의 실질 파라미터는 이동평균 기간 1개다.
3. **데이터 요구가 낮아야 시작할 수 있다.** 일봉 수정 종가만 있으면 신호를 만들 수 있다. 분봉·호가·뉴스·재무 데이터가 필요 없다.
4. **재실행해도 같은 결과여야 한다.** 신호는 상태가 아니라 목표 비중이며, 목표와 현재 보유의 차이만 주문한다. 몇 번을 다시 실행해도 중복 매수가 발생하지 않는다.

## 4. 신호

```
SMA120(t) = 최근 120 거래일 수정 종가의 단순평균  (t 포함)
d         = 직전 확정 거래일
signal(d) = close(d) > SMA120(d) * (1 + band)  →  HOLD
            close(d) < SMA120(d) * (1 - band)  →  CASH
            그 외                              →  직전 신호 유지
목표비중(d) = signal(d) == HOLD ? MAX_EXPOSURE : 0
```

**재계산 주기: 주 1회.** 매주 첫 개장일에만 목표 비중을 다시 계산한다. 주중에는 신호를 재평가하지 않는다. 주 1회로 고정하는 이유는 신호 품질이 아니라 회전율 억제다.

리밸런싱 요일이 휴장이면 그 주의 다음 개장일로 이월한다. 해당 주에 개장일이 없으면 건너뛴다. 이월된 실행도 신호는 **그 실행일의 직전 확정 종가**로 다시 계산한다.

## 5. 파라미터

근거 등급을 함께 적는다. `시작값`은 연구 시작점일 뿐 최적값이라는 근거가 없다는 뜻이다.

| 파라미터 | v0.1 값 | 근거 등급 | 비고 |
| --- | ---: | --- | --- |
| `smaPeriod` | 120 | 시작값 | 선택 구간에서 {60, 120, 200} 3개만 비교한다. 그 외 값은 탐색하지 않는다 |
| `band` | 0.0% | 고정 | 휩소 억제용 밴드. v0.1은 파라미터 수를 줄이기 위해 0으로 고정한다. {0%, 0.5%} 2개만 선택 구간에서 비교한다 |
| `rebalanceFrequency` | 주 1회 | 고정 | 비용 제약에서 나온 값이므로 탐색 대상이 아니다 |
| `maxExposure` | 60% | 고정 | 위험 한도에서 나온 값이므로 탐색 대상이 아니다 |
| `minRebalanceRatio` | 5% | 시작값 | 목표와 현재 비중 차이가 이 미만이면 주문하지 않는다 |
| `limitBandRatio` | 0.3% | 시작값 | 지정가 허용 범위 |
| `unfilledTimeoutMinutes` | 10 | 시작값 | 미체결 취소 기준 |

**탐색 가능한 조합은 `smaPeriod` 3개 × `band` 2개 = 6가지뿐이다.** 이 외의 조합을 시험하면 그 사실과 결과를 모두 기록에 남긴다. 탐색 이력을 남기지 않은 결과는 채택 근거로 쓰지 않는다.

## 6. 수량 계산

```
순자산      = 현금 + 유가평가액                  (미결제·미수 제외)
목표금액    = 순자산 × 목표비중
예상단가    = 현재가 × (1 + 편도비용률)
목표수량    = floor(목표금액 / 예상단가)

유효보유    = 보유수량 + 미체결매수수량 - 미체결매도수량
주문수량    = 목표수량 - 유효보유

if |주문수량 × 현재가| < 순자산 × minRebalanceRatio  →  주문하지 않음
if 주문수량 == 0                                      →  주문하지 않음

매수 시 추가 상한:
  주문수량 ≤ floor(예약 차감 후 미수 없는 매수가능액 / 예상단가)
  주문수량 ≤ floor((전체노출한도 - 현재노출) / 예상단가)
매도 시 추가 상한:
  주문수량 ≤ 매도가능수량
```

`유효보유`에 미체결 주문을 포함하는 것이 재실행 안전성의 핵심이다. 이 항이 없으면 주문 접수 후 체결 전에 전략이 다시 실행될 때 같은 수량을 또 매수한다. 1주도 살 수 없으면 거래하지 않는다.

## 7. 주문 실행

| 항목 | 규칙 |
| --- | --- |
| 실행 시각 | 09:05 이후. 시가 형성 직후 변동성 구간을 피한다 |
| 신규 주문 마감 | 15:00. 이후에는 취소·조회·위험 축소 매도만 허용한다 |
| 주문 유형 | 지정가. 시장가를 쓰지 않는다 |
| 매수 지정가 | 최우선 매도호가 기준 `+limitBandRatio` 이내에서 호가 단위로 절사 |
| 매도 지정가 | 최우선 매수호가 기준 `-limitBandRatio` 이내에서 호가 단위로 절상 |
| 미체결 처리 | `unfilledTimeoutMinutes` 경과 시 취소 → **취소 확인 후** 잔량으로 1회만 재산정 주문 → 그래도 미체결이면 당일 포기 |
| 가격 추격 | 금지. 재시도는 1회로 제한하고 허용 범위를 넓히지 않는다 |
| 분할 주문 | 하지 않는다. 100만 원 규모에서 분할은 비용만 늘린다 |

주문 전에 다음을 모두 확인하고, 하나라도 실패하면 주문하지 않는다.

1. 시세가 최신인가 (마지막 체결 시각이 허용 지연 이내인가)
2. 해당 종목이 거래정지·정리매매 상태가 아닌가
3. 정규장 세션이 열려 있는가 (휴장·임시 휴장·단축장 캘린더 반영)
4. 미확인(`unknown`) 상태의 주문이 남아 있지 않은가
5. DB 중지 플래그가 꺼져 있는가 (환경변수가 아니라 **주문 직전 DB 재확인**)
6. 주문 원장을 영속화할 수 있는가

손절·중지선은 손실액 보장이 아니다. 갭 하락, 거래정지, 통신 장애에서는 한도를 넘는 손실이 발생할 수 있다.

## 9. 이 전략이 하지 않는 것

명시적으로 범위 밖이다. 성과가 나쁠 때 아래를 추가하는 방향으로 대응하지 않는다.

- **개별 종목 손절선**: 청산 조건은 이동평균 이탈 하나뿐이다. 손절선을 추가하면 파라미터가 늘고 추세 전략의 손익 분포가 무너진다.
- **물타기·불타기**: 목표 비중은 신호에만 의존하며 평가손익에 반응하지 않는다.
- **레버리지·인버스·신용**: 사용하지 않는다.
- **장중 신호 재평가**: 주중 가격 변동에 반응하지 않는다.
- **종목 교체·추가**: 유니버스는 1종 고정이다. 성과가 안 나온다고 종목을 바꿔가며 재시험하면 그것 자체가 과적합이다.
- **거래 빈도 상향**: 목표 수익에 미달한다는 이유로 재계산 주기를 줄이지 않는다.

## 10. 백테스트 검증 기준

| 항목 | 규칙 |
| --- | --- |
| 체결 가정 | 신호일 **다음 거래일 시가** + 보수적 비용. 7절의 09:05 지정가와 동일하다고 주장하지 않으며, 실전 판단 전 분봉/호가 또는 paper 기록으로 차이를 실측한다 |
| 비용 모델 | 수수료(계좌 실측), 슬리피지(paper 실측), 매도세(상품 분류 확인 후). 기본값과 2배 가정 두 가지로 시험 |
| 구간 분리 | 시간순 개발 60% / 선택 20% / 최종 평가 20%. 워밍업 구간은 허용 |
| 워크포워드 | 구간을 이동시키며 반복 평가 |
| 비교군 | ① 현금 유지 ② 매수 후 보유 ③ 동일 `maxExposure`로 맞춘 매수 후 보유. 분배금·비용 동일 반영 |
| 스트레스 | 주문 지연, 미체결, 갭, 거래정지, 데이터 누락 사례 포함 |

보고 지표: 비용 후 월별 순수익, 평균·중앙값·최악 월, 손실 월 비율, 최대 낙폭, 회복 기간, 평균 노출, 연 회전율, 거래당 기대손익, 거래 표본 수.

기대손익은 `승률 × 평균 순이익 - 패배율 × 평균 순손실`로 계산한다. 승률만으로 채택하지 않는다. 최종 보유분은 평가손익으로 분리하고 청산 비용 민감도를 별도 제시한다.

**채택 조건** — 모두 충족해야 다음 단계로 넘어간다.

1. 최종 미사용 구간에서 비용 차감 후 기대손익 > 0
2. 여러 기간에서 일관 (특정 한 구간에 성과가 몰려 있지 않을 것)
3. 비용 2배 가정에서도 기대손익 > 0
4. 최대 낙폭 8% 이내
5. 비교군 대비 수익 또는 위험 측면에서 설명 가능한 이점

최종 평가 구간을 보고 파라미터를 다시 조정하면 그 구간은 더 이상 미사용 평가가 아니다. 조건을 모두 통과해도 미래 수익 보장이 아니다.

## 11. 기대 성과에 대한 사전 고지

가장 널리 인용되는 동류 전략(Faber 10개월 SMA, 1973–2008)의 백테스트 성과는 CAGR 11.27%, 변동성 6.87%, 최대낙폭 -29.43%다. 단일 국내 ETF에 단일 이동평균을 적용하는 이 전략은 그보다 분산이 낮으므로 낙폭이 더 클 수 있다.

**따라서 이 전략의 현실적 기대치는 비용 차감 후 연 한 자릿수에서 10%대이며, 손실 월과 두 자릿수 낙폭 구간을 포함한다. 월 10%가 아니다.** 이 격차를 메우기 위해 9절의 금지 항목을 도입하는 것이 이 전략을 실패시키는 가장 흔한 경로다.

### `StrategyContext`에 없어서 추가해야 하는 것

현재 `src/lib/engine/tradingEngine.ts:36`은 `quoteHistory: [quote]`, `orderHistory: []`를 넘긴다. 시세 이력이 1개뿐이라 **지금 구조로는 120일 이동평균을 계산할 수 없다.** 아래가 선행 조건이다.

| 필요한 것 | 현재 상태 |
| --- | --- |
| 일봉 시계열 (120건 이상, 수정 종가) | 없음. `quoteHistory`는 실행 시 1건 |
| 미체결 매수·매도 수량 | 없음. `orderHistory`는 실행 시 빈 배열 |
| 현금 / 유가평가액 / 순자산 분리 | 혼재. `totalMarketValue`에 총평가액이 들어가 현금이 중복 계산될 수 있음 |
| 미수 없는 매수가능액·매도가능수량 | 없음. 브로커 조회 추가 필요 |
| 마지막 리밸런싱 일자 | 없음. 주 1회 판정에 필요 |

즉 **이 전략은 지금 바로 구현할 수 없다.** 선행 문서의 1단계(계좌·주문 기반)와 2단계(데이터·백테스트)가 끝나야 3단계에서 구현 가능하다. 그 전에 억지로 구현하면 신호가 틀린 채로 주문이 나간다.
