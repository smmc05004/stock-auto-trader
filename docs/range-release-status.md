## 자동 취소 검증 추가 배포

- 자동 사전 검증 실행 코드와 주문 없는 시세 연결 진단을 EC2 이미지 `sha256:d121e4f5d1cc50b91e16e8da8dfcc993d4bfdda06776254e39166fd52338ba0f`에 반영하고 컨테이너 재생성 완료.
- WebSocket 호가 H0STASP0·체결 H0STCNT0 구독 접수 모두 OPSP0000 성공. 장외 진단에서 실제 호가/체결 수신은 각각 0건이므로 장중 시세 검증 완료로 보지 않는다. 진단 주문 제출 0건.
- 전체 52개 테스트, TypeScript, ESLint 및 서버 번들·Docker 빌드 통과. 취소 접수만으로 주문을 열지 않는 테스트와 예상 밖 체결 시 청산 후 검증 실패 처리 테스트 포함.
- 수수료 미확정으로 기존 관찰 설정을 유지했다. 사용자에게 편도 0.02% 가정 사용 여부를 질문했으며 아직 답변을 받지 못했다. 자동 사전 검증은 배포됐지만 설정상 비활성 상태다. 수수료 합의 후 `RANGE_AUTO_PREFLIGHT=true`, `RANGE_ORDERS_ENABLED=true`, 합의한 요율과 근거를 함께 설정해야 한다. 취소 검증 플래그는 false로 유지한다.

## 후속 인증 오류 수정

REST 당일 주문조회에서 HTTP 500 / EGW00123(기간이 만료된 token)을 확인했다. 인증 발급 및 별도 현재가 조회는 성공했지만 저장 토큰의 주문조회는 거절됐다. 로컬 만료 시각만 믿지 않고 EGW00123 응답에서 캐시를 우회해 재발급하도록 수정했다. 요청은 재전송하지 않으며 다음 대조에서 확인한다. 이 수정 포함 이미지: `sha256:fe65196bce6bbf1de567ad0933d690e3195b6bfa67077cfd3c9ca5b17fecfc8c`.

수정 배포 후 최종 대조: `status=running`, `safeToStop=true`, 보유 0, 주문 목록 없음. 토큰 만료에 따른 계좌 대조 오류 복구 확인. `ordersArmed=false` 관찰 모드 유지.
